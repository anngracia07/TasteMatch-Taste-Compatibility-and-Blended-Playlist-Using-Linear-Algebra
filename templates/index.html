MODEL NOTES

How to read this application

Standardization

One StandardScaler is fitted to the entire dataset. It puts all seven musical features into a comparable coordinate system so geometry is not dominated by measurement units.

Full span vs taste model

Rank and nullity describe the full selected-song span. Three dimensions are a modeling approximation used for subspace comparison.

Gram–Schmidt vs PCA

The explicit Gram–Schmidt basis defines taste subspaces. PCA describes variation and supplies the common visualization coordinates; it does not replace QA or QB.

Baseline vs core method

Average-vector cosine is a simple reference point. Principal angles compare the geometry of both modeled subspaces and are the core compatibility method.

Playlist fit

Projection fits and shared-space fit are normalized geometric scores. Projection error is the residual distance to the shared subspace.

Interpretation

Compatibility is a geometric score, not a probability. Synthetic profiles and this small supplied dataset make the result an educational model.
